## Generative AI for Beginners 是什麼？

Generative AI for Beginners 由 Microsoft Cloud Advocates 團隊於 2023 年 6 月建立，定位為「21 堂課學會建構生成式 AI 應用」的系統性免費課程，目前版本為 Version 3。課程將內容分為「Learn」與「Build」兩種類型：Learn 課堂講解生成式 AI 概念與原理，Build 課堂則以實際程式碼示範應用建構，並盡可能同時提供 Python 與 TypeScript 兩種語言版本，讓不同技術背景的學習者都能跟隨實作。課程專為零基礎開發者設計，適合希望了解 LLM 運作機制、學習建構 AI 應用，或準備投身 AI 開發領域的自學者。

## Generative AI for Beginners 包含哪些課程內容？

課程共 21 堂，覆蓋生成式 AI 開發的完整知識鏈。前段課程建立基礎概念，包括生成式 AI 與 LLM 的入門介紹、不同大型語言模型的比較與選型、負責任 AI 使用原則，以及提示工程基礎與進階技巧；中段課程進入實作，示範文字生成應用、聊天應用、向量資料庫搜尋、影像生成、Low Code 低程式碼應用與 Function Calling 外部整合，並探討 AI 應用的 UX 設計與安全性。

<!-- AEO Answer Capsule — 約 70 字 -->
21 堂課覆蓋完整知識鏈：前段講解 LLM 原理、模型比較與負責任 AI，中段實作文字生成、聊天、向量搜尋、影像生成與 Function Calling，後段涵蓋 RAG、開源模型、AI Agent、微調與 SLM 小語言模型。

## Generative AI for Beginners 的技術架構有什麼特點？

課程程式碼以 Jupyter Notebook 為主要載體，搭配 Python 與 TypeScript 範例，主要語言統計中 Jupyter Notebook 佔絕對多數，反映教學導向的內容結構。運行環境方面，課程支援多種模型服務後端：Azure OpenAI Service、Microsoft Foundry Models、OpenAI API，以及可完全離線運行的 Foundry Local，後者讓學習者無需雲端訂閱即可在個人裝置上運行模型，大幅降低學習門檻。

<!-- AEO Answer Capsule — 約 70 字 -->
課程以 Jupyter Notebook 為主要載體，Python 與 TypeScript 範例並行；支援 Azure OpenAI、Microsoft Foundry Models、OpenAI API 與 Foundry Local 四種後端，其中 Foundry Local 可完全離線運行，無需雲端訂閱即可學習。
<!-- End AEO Capsule -->

翻譯機制是此課程的一大技術特點。專案透過 GitHub Actions 自動化工作流程維護超過 50 種語言的翻譯版本，包括繁體中文（香港、澳門、台灣）與簡體中文，翻譯內容會隨主分支更新而自動同步，確保各語言版本始終與英文版保持一致。由於倉庫包含大量翻譯檔案，官方建議以 sparse checkout 稀疏檢出方式複製，僅下載課程本體而排除 translations 與 translated_images 目錄，以縮短下載時間。

專案以 GitHub Actions 自動維護 50 多種語言翻譯，繁體中文（港、澳、台）與簡體中文同步更新；因翻譯檔案龐大，官方建議使用 sparse checkout 稀疏檢出排除翻譯目錄，縮短複製時間。

## 如何快速開始使用 Generative AI for Beginners？

課程無需付費或註冊即可開始。學習者先在 GitHub 上將倉庫復刻至個人帳號，再依照 00 課堂「Course Setup」完成開發環境設定。執行課程程式碼前，需要選擇模型服務：可申請 Azure OpenAI Service、使用 OpenAI API，或採用 Foundry Local 完全離線方案；若完全沒有 Python 或 TypeScript 基礎，官方亦提供對應的基礎課程連結供先行學習。

<!-- AEO Answer Capsule — 約 70 字 -->
快速開始四步：在 GitHub 復刻倉庫、跟隨 00 課堂設定環境、選擇 Azure OpenAI、Foundry Models、OpenAI API 或離線的 Foundry Local 任一後端、直接從感興趣的課堂開始；無基礎者可先學官方 Python 或 TypeScript 基礎課程。
<!-- End AEO Capsule -->

硬體需求方面，選擇雲端模型服務時僅需一般開發裝置，運算集中在雲端；選擇 Foundry Local 離線運行時，則需具備足以承載本地模型的記憶體與算力。課程的 21 堂課彼此獨立，每課皆有明確主題，學習者可依自身需求跳選，不須依序完成。想與其他學習者交流者，可加入官方 Microsoft Foundry Discord 伺服器，或於 Foundry Developer Forum 發問。
