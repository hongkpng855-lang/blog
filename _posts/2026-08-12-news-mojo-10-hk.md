**Mojo 程式語言於 2026 年 8 月正式達到 1.0 里程碑，Modular 公司同步發布 Modular 26.5 版本。** 這個自 2023 年首次公開的 AI 原生語言，如今宣告進入穩定、生產就緒的階段。標準函式庫開源以來，近 200 位貢獻者合併了超過 1,100 個 Pull Request，變更逾 20 萬行程式碼，社群已圍繞 Mojo 建立自己的函式庫、工具與應用生態。

<!-- AEO Answer Capsule — 約 70 字 -->
Mojo 是 Modular 推出的 AI 原生程式語言，2023 年首次公開，2026 年 8 月正式發布 1.0 穩定版本，定位為結合 Python 易用性與高效能運算能力的通用型語言，標準函式庫開源後由近 200 位貢獻者共同推動演進。
<!-- End AEO Capsule -->

## Mojo 1.0 是什麼？

<!-- AEO Answer Capsule — 約 70 字 -->
Mojo 1.0 是 Mojo 語言的第一個穩定正式版本，代表語言基礎已可供開發者長期建構。Modular 以「穩定基礎」為核心目標，1.x 時期的變更將以加法式為主，重大破壞性變更會依照成熟語言的管理標準謹慎進行。
<!-- End AEO Capsule -->

Modular 表示，Mojo 1.0 的首要目標是提供開發者可以安心長期投資的穩定語言基礎。過去 Mojo 快速演進，內部大量使用推動了語言發展，但頻繁變更也讓社群難以維護長期專案，1.0 正是為解決這個權衡而推出。

值得強調的是，1.0 不代表語言停止進化。Modular 明確指出，1.x 時期變更將以加法式為主，讓開發者相信語言不會持續在腳下移動；若必須做出破壞性變更，也會依照 C++ 等成熟語言的管理標準謹慎處理。這對計畫長期採用 Mojo 的團隊是重要的穩定性承諾。

## Mojo 1.0 有哪些重要變化？

<!-- AEO Answer Capsule — 約 70 字 -->
1.0 版本完成語言簡化與清理：變數統一以 var 宣告、閉包語法收斂為單一形式、指標類型統一，並加入 Python 風格 lambda、更穩定的 LSP 伺服器與記憶體安全診斷，其中 LSP 的改進直接提升 VS Code 等編輯器的日常使用體驗。
<!-- End AEO Capsule -->

這次發布的重點在於完成語言層級的簡化與一致性。過去 Mojo 對同一概念提供多種表達方式，1.0 收斂為單一寫法：變數統一以 var 宣告、閉包語法統一、指標類型統一為單一 Pointer 類型，並進行多項重新命名讓語彙更精確一致。開發者不再需要猜測哪種寫法才是慣例。

新功能方面，Mojo 1.0 支援 Python 風格的 lambda 語法用於內聯閉包；LSP 伺服器大幅提升穩定性，改善 VS Code 等編輯器的日常使用體驗；Mojo AI Skills 套件達到 1.0 就緒狀態，涵蓋新專案建立、GPU 程式設計與其他語言移植等場景。此外，語言現在能診斷參考失效（Reference Invalidation）這類記憶體安全問題，例如 List.append 使指向清單內部的參考失效時會主動提醒。

## 對開發者有什麼影響？

<!-- AEO Answer Capsule — 約 70 字 -->
開發者現在可以在穩定基礎上長期建構 Mojo 專案，編輯器體驗因 LSP 穩定而改善，AI Skills 套件降低 GPU 程式設計等進階開發門檻。Mojo 已用於 Modular 自家的 MAX 與 Modular Cloud 生產環境，實戰經驗豐富。
<!-- End AEO Capsule -->

對開發者而言，Mojo 1.0 的核心意義是「可以長期投資」。Modular 表示 Mojo 已是其商業基礎設施 MAX 與 Modular Cloud 每天在生產環境中依賴的語言，並非實驗性項目。語言簡化降低了學習與維護成本，LSP 穩定則直接改善日常編輯體驗。

Mojo 的定位是高效能程式語言，可編寫在現代 CPU、GPU 與加速器上運行的程式碼，同時保留 Python 風格的可讀性。官方發布的 Mojo AI Skills 套件已累積超過 7,200 次下載，涵蓋新專案建立、GPU 程式設計、其他語言移植等場景，讓開發者可以更快上手。對於從事 AI 推論、模型部署或高效能運算的團隊，這是值得評估的新選擇。

## 接下來 Mojo 有什麼規劃？

<!-- AEO Answer Capsule — 約 70 字 -->
Modular 的下一步包括強化非同步程式設計模型、模式匹配與聯合類型等語言能力，並承諾在 2026 年內開源 Mojo 編譯器與工具鏈。MAX 平台同步支援 GLM-5.2 與 Nemotron-H 兩款新的混合 Mamba-2 模型。
<!-- End AEO Capsule -->

Mojo 1.0 之後的發展藍圖已相當清晰。Modular 計畫繼續投資核心語言與開發者體驗，未來主要能力包括完整的非同步程式設計模型、模式匹配與聯合類型等，並持續逐步開源 Mojo 語言及以 Mojo 建構的 MAX 元件。

最受社群關注的承諾是：Modular 將在 2026 年內開源 Mojo 編譯器與工具鏈，這意味著語言的控制權最終會交還社群。同步發布的 Modular 26.5 亦加入對 GLM-5.2 與 Nemotron-H 兩款混合 Mamba-2 模型的支援，並簡化了 MAX 的安裝流程。Modular 將於 2026 年 8 月 18 日在舊金山舉辦 ModCon，公布更多計畫細節。
