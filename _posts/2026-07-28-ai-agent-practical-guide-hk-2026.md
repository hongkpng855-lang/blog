## 咩係 AI Agent？同普通 AI 對話有咩分別？

普通人用 AI 嘅方式：你問一句，AI 答一句。每次都要你俾指令，AI 唔會主動做嘢。

**AI Agent 嘅方式**：你俾一個目標，AI 自己規劃步驟、執行任務、甚至遇到問題時自己調整方法，最後交結果俾你。

簡單講，普通 AI Chatbot 係「問答機」，AI Agent 係**你嘅虛擬員工**。

## Claude Computer Use：真正「幫你用電腦」嘅 AI

Claude 嘅 Computer Use 係 2026 年最令人驚喜嘅 AI Agent 功能之一。佢可以**直接控制你嘅電腦畫面**，好似一個人喺遠端幫你操作一樣。

### 實戰場景 1：資料整理

假設你要每個月整理幾十份 PDF 發票入 Excel：

```
你：「幫我將 Downloads Folder 入面所有 7 月發票 PDF，
    提取日期、金額、供應商名稱，
    整理成 Excel 表格，放喺 Desktop。」
Claude：打開 PDF → 逐份擷取資料 → 開 Excel → 填入資料 → 儲存 ✅
```

以前要做半日嘅嘢，而家 5 分鐘搞掂。

### 實戰場景 2：表格填寫

香港最多人頭痛嘅嘢——填政府表格。

```
你：「幫我打開呢個 PDF 公司註冊表格，
    根據我俾你嘅資料填入對應欄位，
    然後 export 做已填好嘅 PDF。」
```

Claude 會識別表格欄位，逐格填入，遇到唔肯定嘅會停低問你。

⚠️ **提提你**：涉及敏感個人資料嘅表格，建議喺本地電腦用 Claude Desktop 版處理，唔好上傳去雲端。安全第一。

## ChatGPT Tasks：你嘅 24/7 虛擬助理

ChatGPT 嘅 Tasks 功能令你可以設定**定時自動執行**嘅任務。Set 一次，以後日日自動做。

### 實戰場景 1：每日市場摘要

```
Task：每個工作天朝早 8:30，
      幫我 summarize 美股/港股/A股三大指數嘅昨日表現，
      列出 3 個最影響今日市場嘅新聞，
      用 point form 200 字內。
```

以後朝早打開 ChatGPT，佢已經幫你準備好晒。

### 實戰場景 2：自動文章撰寫

```
Task：每星期三同五下晝 3 點，
      幫我根據指定嘅 Blog topics，
      寫一篇 800 字中文文章 draft。
```

內容創作者、社交媒體小編嘅神器。

## 香港人用 AI Agent 要留意嘅 5 件事

### 1. 語言：廣東話支援
2026 年，Claude 同 ChatGPT 對廣東話嘅理解已經好好，但寫正式文件嗰陣，建議你用**書面中文**做 prompt，準確度更高。

### 2. 私隱：敏感資料唔好亂交
- ❌ 唔好將身份證號碼、地址、銀行資料直接貼去公共 AI 平台
- ✅ 用 Claude Desktop（本地運算）處理敏感文件
- ✅ 用公司嘅 Enterprise 版本（資料唔用於訓練）

### 3. 事實核查：AI 仍然會錯
AI Agent 做咗嘢之後，你一定要**覆檢一次**。尤其係數字、日期、人名呢啲細節，AI 有時會「作嘢」（hallucination）。

### 4. 成本效益
- Personal 用量：ChatGPT Plus (US$20/月) + Claude Pro (US$20/月) — 每月約 HK$310
- 輕量用戶：免費版 ChatGPT + Gemini 已經夠用
- 公司用：Microsoft 365 Copilot (US$30/月) — 如果公司已有 M365，值得升級

### 5. 學習曲線
AI Agent 唔似普通 Chatbot 咁即開即用。你需要：
- **頭 1-2 週**：摸索期，試唔同 prompt
- **第 3-4 週**：開始搵到適合自己嘅 workflow
- **第 2 個月**：真正用得順，開始見到時間節省效果

## 2026 AI Agent 入門 3 步曲

## 常見問題（FAQ）

**Q：AI Agent 會唔會取代我份工？**
A：2026 年嘅 AI Agent 係「幫你做嘢」而唔係「取代你」。佢自動化嘅係重複性任務（整理資料、寫 draft、分類 email），但你嘅判斷力、決策、人際溝通、創意——呢啲反而因為你有更多時間而變得更有價值。

**Q：用邊個平台最好？**
A：冇絕對最好，視乎你需要：
- 日常助理 → ChatGPT Tasks
- 複雜文件分析 → Claude
- Office 整合 → Microsoft Copilot
- Google 生態 → Gemini

**Q：AI Agent 安全嗎？**
A：主流平台嘅安全機制已經好成熟。關鍵係你點用——敏感資料用本地處理、設定強密碼、啟用 2FA、定期檢查 Agent 嘅存取權限。
